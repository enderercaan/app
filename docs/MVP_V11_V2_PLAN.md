# Tailmance Delivery Plan

## MVP
Auth + 18+ gate; onboarding; multi-pet profiles; document verification; discovery/matches; chat + asymmetric unlock/quota; moderation/block/report; RevenueCat paywall; 19-locale runtime; privacy/deletion; accessibility; crash reporting; store compliance; support/moderation operations.

## v1.1
Grid/feed posts; 24-hour Stories; Pati Radar; Universal/App Links; on-device pet/safety prefilter; media optimization/WebP pipeline; advanced-filter polish; referral/share and density growth tools.

## v2
Reels; matched-pet audio/video calls; multi-region/DR hardening; KEDA/queue autoscaling; chaos exercises; FinOps dashboards and deeper capacity automation.

## Source reality
The authoritative codebase already contains substantial v1.1/v2 implementation. The tier labels above remain product/release milestones, not an instruction to delete already-built forward-compatible code. Features stay fail-closed behind release evidence and policy gates until eligible for production.
