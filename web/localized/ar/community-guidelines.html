إرشادات المجتمع

تطبق هذه القواعد مع الشروط للحفاظ على Tailmance بيئة محترمة وآمنة وتركز على رعاية الحيوان. ويكون للقانون المحلي الأكثر صرامة والأكثر قابلية للتطبيق الأولوية.

1. احترام الأشخاص والحيوانات

لا تسئ إلى الحيوانات أو تعرضها للخطر، ولا تتحرش بالآخرين أو تهددهم أو تطاردهم أو تستغلهم أو تميز ضدهم أو توجه الكراهية إليهم. ولا تشجع التعامل غير الآمن مع الحيوانات أو تخفي مخاطر جوهرية على رفاهها.

2. الاستغلال الجنسي وسلامة الأطفال

تُحظر مواد الاعتداء الجنسي على الأطفال، والاستغلال الجنسي للقاصرين، والاستدراج، والإغراء الجنسي، والمحتوى الذي يسهل مثل هذه الأفعال. ويجوز لـ Tailmance حفظ المواد أو تقييدها أو الإبلاغ عنها حيثما يتطلب القانون، ويوفر قناة اتصال لسلامة الأطفال.

3. الملفات الحقيقية والادعاءات الصحية

لا تنتحل هوية أشخاص، ولا تقدم معلومات مضللة عن ملكية الحيوان أو سلالته أو عمره أو جنسه أو صحته أو تطعيمه أو حالة التحقق، ولا تقدم مستندات مزورة. وشارات التحقق ليست ضمانًا بيطريًا.

قد يخطئ الذكاء الاصطناعي. فحوص الوثائق المدعومة بالذكاء الاصطناعي أولية فقط: فهي لا تتخذ قرارًا نهائيًا أو صحيحًا قانونيًا بشأن صحة الحيوان، وليست مشورة بيطرية، ولا تضمن الحالة الصحية أو حالة التطعيم. استشر دائمًا طبيبًا بيطريًا مرخّصًا.

4. الخصوصية والمحتوى الحميم

لا تشارك دون تصريح بيانات شخص آخر الخاصة أو موقعه الدقيق أو بيانات اعتماده أو معلوماته الطبية أو صوره الحميمة. وتجنب إدراج بيانات شخصية غير ضرورية لأطراف ثالثة في سجلات الحيوان أو الرسائل.

5. السلع غير القانونية والاحتيال والسلوك الخطير

لا تستخدم Tailmance في الاحتيال أو السلع أو الخدمات غير القانونية أو الأسلحة أو الأنشطة الخطرة أو المخططات المالية غير المصرح بها أو السلوك الذي يسهل الجريمة أو التحايل على ضوابط السلامة القانونية.

6. بيع الحيوانات والتربية التجارية

Tailmance ليس سوقًا لبيع الحيوانات أو للمربين. ويُحظر التفاوض على الأسعار والعربون وبيع الحيوانات أو تسليمها وتوليد العملاء للمربين التجاريين والتربية غير المشروعة والاتجار ونشاط مزارع الجراء. ولا يجوز أيضًا استخدام الخدمة لعرض أو طلب أو التوسط في أو تنظيم تبني حيوان أليف أو إعادة تسكينه أو نقل ملكيته.

7. التزاوج ورعاية الحيوان

تكون ميزات التزاوج معطلة افتراضيًا ولا يمكن تفعيلها إلا بعد اعتماد ضوابط قانونية وضوابط رعاية وعمر وصحة وقرابة خاصة بالبلد. ويجب ألا يستخدم المستخدمون الخدمة لتشجيع التربية الضارة أو غير القانونية.

8. الإبلاغ والحظر والإشراف

استخدم أدوات الإبلاغ والحظر داخل التطبيق لمخاوف السلامة. ويجوز لـ Tailmance إزالة أو تقييد المحتوى أو الحسابات، ويوفر الأسباب ومسارات الاعتراض عندما يكون ذلك مناسبًا ومطلوبًا قانونًا.

9. القواعد المحلية

قد تضيف الواجبات الخاصة بالبلد أو المنطقة بشأن المحتوى غير القانوني وسلامة الأطفال ورعاية الحيوان والإبلاغ والحفظ وإنفاذ القانون متطلبات إلى هذه الإرشادات. ويطبق Tailmance القاعدة الأكثر صرامة حيثما يقتضي الأمر.
